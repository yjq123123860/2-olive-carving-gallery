榄雕非遗出海 · 四个演示原型 —— GitHub Pages 部署说明
========================================================

我把四个演示站各做成一个文件夹，放在你桌面了。
每个文件夹里只有两个文件（index.html + README.md），
你要做的就是：建仓库 → 把文件夹里的东西拖进去 → 开 Pages。


--------------------------------------------------------
一、桌面上的四个文件夹
--------------------------------------------------------

  1-olive-carving-scroll      2.8 MB   长卷 · 从果到核
  2-olive-carving-gallery     3.0 MB   陈列馆 · 18 件馆藏
  3-olive-carving-inspect    10.5 MB   检视台 · 核舟微刻 3D
  4-olive-carving-abacus      0.2 MB   算盘 · 出海推演

每个文件夹里的文件完全一样：
  index.html    ← 站点本体，双击就能打开，不要改名
  README.md     ← 仓库说明，会显示在 GitHub 仓库主页


--------------------------------------------------------
二、建仓库（四个仓库重复四遍）
--------------------------------------------------------

第1 步  浏览器打开 https://github.com/new
         （github.com 在国内需要梯子；页面能打开就说明梯子没问题）

第 2 步  填写：
           Repository name : 与桌面文件夹同名，如 1-olive-carving-scroll
           Description     : 随便写，如「榄雕工艺长卷演示原型」
           勾选  Public      ← 必须选 Public，Private 仓库不开 Pages
           勾选  Add a README file   ← 有了它仓库才有 main 分支
         点 Create repository

第 3 步  仓库建好后，点上方绿色按钮
           "uploading an existing file"（Add file → Upload files）

第 4 步  把桌面那个文件夹里的两个文件
         拖进网页上传框（或点 browse your files 选中）

第 5 步  拉到最下方，点 Commit changes

第 6 步  等十几秒，页面刷新，能看到 index.html 和 README.md 已在列表里


--------------------------------------------------------
三、开启 Pages（每个仓库都要做一次）
--------------------------------------------------------

第 1 步  进仓库 →顶部 Settings（Settings 标签）

第 2 步  左侧栏点 Pages

第 3 步  Source 选  Deploy from a branch
         Branch 选 main，目录选 / (root)
         点Save

第 4 步  等 1–2 分钟，刷新 Pages 页面，
         顶部会出现 Your site is live at …
         形如：
         https://你的用户名.github.io/1-olive-carving-scroll/

--------------------------------------------------------
五、可能遇到的问题
--------------------------------------------------------

Q: 页面提示 "Your site is live at…" 但打开是 404？
A: 常见原因是没选对分支。回 Settings → Pages，
   Branch 一定要选 main（不是 gh-pages），目录选 / (root)。

Q: 上传时提示文件太大？
A: 不会。GitHub 单文件上限 100MB，最大的检视台才 10.5MB。
   里面是因为内嵌了5.5MB 的 3D 模型（base64 编码后膨胀），属正常。

Q: 检视台打开很慢？
A: 首次要下载 10.5MB 并解码 3D 模型，等十几秒是正常的，
   之后就快了。

Q: 评委打不开 github.io？
A: 实测国内可以访问。但如果评委所在网络刚好不通，
   PPT 里每个按钮下方都写着本地路径，文件包里也有 HTML，
   可以离线演示兜底。

Q: 能不能把四个站放一个仓库？
A: 可以，但那样网址会变成 xxx.github.io/仓库名/子目录/，
   多一层目录。当前一个仓库一个站，网址更短更干净，
   而且每个仓库的 README 能单独写清楚。
